# VoiceMobile

iPhone・iPad向けの録音、音声書き出し、文字起こしクライアントです。

1. GitHubの **Actions → Build iOS IPA → Run workflow** でビルドします。
2. 成功した実行の **VoiceMobile-ipa** を取得してZIPを展開します。IPAとSHA-256を14日間保存します。
3. 既存の録音を引き継ぐ場合は、アプリを削除せず、同じApple IDとAltStoreで `VoiceMobile.ipa` を上書きインストールします。
4. アプリの設定で、ご自身の文字起こしサーバーのHTTPS URLを入力します。接続先の初期値は空欄です。

録音詳細のメニューから **音声を書き出す → WAV / M4A** を選び、共有シートでファイルに保存できます。**最近削除した項目 → 完全に削除** は端末内の元音声も削除します。別途保存・共有したコピーとサーバー側のファイルは、それぞれの保存先で管理します。
